# AutoHotkey 効率化 &amp; マウスコンボスクリプト

AutoHotkey v2 で動作する、キーボード＆マウス操作の生産性を極限まで高めるための作業効率化スクリプトです。

マウスコンボによる直感的なコピー＆ペースト・ズーム・検索機能や、一時的なクリック連射・放置自動クリック機能を1つのスクリプトに統合しています。

---

## 🌟 主な機能

### 1\. 🖱️ マウスコンボ操作（通常時）

マウスのボタンを組み合わせるだけで、キーボードに手を伸ばさずに素早く操作できます。

* **左押し ＋ 右クリック（短押し）**: スマートコピー（`Ctrl + C`）

  * 二重コピー防止、音とツールチップによる成否通知付き
* **左押し ＋ 右長押し（0.25秒）**: 選択テキストをGoogle検索
* **右押し ＋ 左クリック**: 貼り付け（`Ctrl + V`）

  * Google スプレッドシート等にも自動対応
* **右押し ＋ 左ダブルクリック**: 貼り付け ＋ `Enter`
* **右押し ＋ ホイール上下**: 画面のズームイン / ズームアウト（`Ctrl + ホイール`）
* **右押し ＋ ホイールクリック**: ズームリセット（`Ctrl + 0`）

---

### 2\. ⌨️ 右Altレイヤー &amp; ショートカット

日本語配列等で余りがちな「右Alt」を活用した便利なショートカット機能です。

* **`右Alt` \+ `S`**: 選択中のテキスト（または入力ダイアログ）でGoogle検索
* **`右Alt` \+ `D`**: 日付の自動入力（例: `- 20260312`）
* **`右Alt` \+ `Shift` \+ `D`**: 秒単位の詳細な日付入力（例: `- 20260312-183000`）
* **`右Alt` \+ `Ctrl` (+ `Shift`) + `D`**: 日付入力後に自動で `Enter` 確定
* **通常動作との両立**: `右Alt + Enter`（プロパティ起動）など、Windows標準のAltショートカットの挙動を邪魔しません。

---

### 3\. 🎮 クリック連射 ＆ 放置自動クリック（ScrollLock連携）

* **`ScrollLock` ON 時（連射モード）**:

  * 左 / 中 / サイドボタン / `Space` キーを「押しっぱなし」にするだけで高速連射
* **`Shift` \+ `ScrollLock`（放置連射モード）**:

  * 画面上の対象キー（マウスボタン等）をクリック指定し、放置して自動連打を実行

---

### 4\. 🛡️ 安全・快適設計

* **自動リロード機能**: スクリプトファイル（`AutoHotkey.ahk`）を編集して `Ctrl + S` 保存するだけで、即座に設定が自動反映されます。
* **アプリ自動除外機能**: リモートデスクトップや特定のゲーム・SSHクライアントなど、コンボ操作を干渉させたくないアプリが最前面の時は自動で機能をサスペンド（一時停止）します。
* **緊急停止**: `Pause` キーで一発リロード＆緊急クリア。

---

## 📋 動作環境

* **OS**: Windows 10 / 11
* **AutoHotkey**: **v2.0 以上** (`AutoHotkey v2.x`)

---

## 🚀 使い方

1. AutoHotkey v2 公式サイトから AutoHotkey v2 をインストールします。
2. このリポジトリの `AutoHotkey.ahk` をダウンロードします。
3. `AutoHotkey.ahk` をダブルクリックして実行します（タスクバーの通知領域に緑色の「H」アイコンが出現します）。

---

## ⚙️ カスタマイズ（設定変更）

`AutoHotkey.ahk` の先頭セクションで簡単に設定を変更できます。

```
; 【セクション0. ユーザー設定】
global R_Interval := 25       ; 左クリック長押し時の連射間隔 (ミリ秒)
global AFK_Interval := 25     ; 放置モードの連射間隔 (ミリ秒)
global MousePlay_px := 5      ; マウス操作の遊び閾値 (px)

; コンボ操作を無効化したいアプリの追加
IsMouseComboExcluded() =&gt; WinActive("ahk_exe dummy.exe")
                       or WinActive("ahk_exe RLogin.exe")

```
